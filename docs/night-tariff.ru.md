# Ночной тариф — Night Tariff Mode

[← Sungrow Energy Manager](../README.md) · [English guide](night-tariff.md)

**Назначение:** автоматически переключать сцены инвертора Sungrow, чтобы в часы скидки дом не разряжал батарею, а вне скидки работал обычный Self-Consumption с разрешённой разрядкой.

## Расписание по умолчанию

**23:00–07:00**, ночи, начинающиеся **с воскресенья по четверг**. Важный нюанс: четверг 23:00 → пятница 07:00 входит в скидку; ночь пятницы и ночь субботы исключены. Время начала и окончания меняется на карточке SEM. Используется локальный часовой пояс Home Assistant. Праздники отдельно не учитываются.

| Время | Выбранная сцена |
|---|---|
| Скидка действует | **Self-Consumption Mode (no battery discharge)** |
| Скидка не действует | **Self-Consumption Mode (max battery discharge)** |
| Идёт Morning Forced Discharge | Принудительная разрядка имеет приоритет; тариф ждёт окончания |

## Установка и включение

1. Открой **Настройки → Устройства и службы → Sungrow Energy Manager → Настроить**.
2. Для обычного режима выбери **Self-Consumption Mode (max battery discharge)**, если сцена ещё не выбрана.
3. В новом поле **Night tariff — no battery discharge scene** выбери **Self-Consumption Mode (no battery discharge)**.
4. На Dashboard открой **Night Tariff Mode**, проверь Discount Start = **23:00**, Discount End = **07:00** и установи **ON**.
5. Проверь `sensor.sem_night_tariff_status` и фактический режим инвертора: в часы скидки батарея должна прекратить разряжаться на дом.

**Критично:** название сцены **не доказывает**, что она действительно запрещает разрядку. На твоём скриншоте сцена `Self-Consumption Mode (no battery discharge)` содержит **Battery max discharge power = 25 000 W**. Один этот параметр не запрещает разрядку. Сначала активируй сцену вручную и проверь фактическую мощность батареи. Если батарея продолжает отдавать энергию, нужно исправить сцену или её команды Sungrow.

## Как функции взаимодействуют

- **Grid Target** может работать одновременно с ночным тарифом; переключатель тарифа независимый.
- **Morning Forced Discharge** приоритетнее ночного тарифа. После завершения разрядки SEM выбирает сцену, соответствующую текущему времени и дню недели.
- Ночной тариф переключает сцену **один раз при смене режима**, а не посылает команду каждую секунду.
- После перезапуска Home Assistant переключатель Night Tariff восстанавливает своё состояние, и SEM проверяет текущий тарифный период.
- При недоступной сцене состояние и ошибка выводятся в `sensor.sem_night_tariff_status`.

## Доступные сущности

| Сущность | Значение |
|---|---|
| `switch.sem_night_tariff` | Включить или выключить функцию |
| `time.sem_tariff_start` | Начало скидки |
| `time.sem_tariff_end` | Конец скидки |
| `sensor.sem_night_tariff_status` | Состояние переключения сцен |

**Безопасность:** SEM — сторонняя интеграция Home Assistant. Она не заменяет ограничения инвертора по экспорту, защиту BMS и резервный SOC. При отсутствии Home Assistant автоматическое переключение не гарантируется.
